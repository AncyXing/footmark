    vuePress-theme-reco    2024

    使用原因

    # 使用原因

    1. 开发环境
    2. 只有数据库表的实体类和mapper文件
    3. 之前建表及对表的修改都是直接操作的数据库，操作后的ddl没有维护和保存好，导致部分建表语句缺失
    4. 连接新数据库

    # 上下文环境

    • 使用mysql数据库
    • mybatis-plus持久层框架
    • 数据库实体类、mapper.xml文件使用mybatis-plus自动生成

    # 解决办法

    # 1.引入依赖

            <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-jpa</artifactId>
        </dependency>

    # 2.修改application.yml配置文件

        jpa:
        hibernate:
            ddl-auto: create
        show-sql: true
        database: mysql
        generate-ddl: true
        database-platform: org.hibernate.dialect.MySQL5InnoDBDialect

    database-platform属性需要指定为org.hibernate.dialect.MySQL5InnoDBDialect，不然默认的存储引擎为MyIsAM

    # 3.修改mybatis-plus自动生成的实体类

    # a.在实体类上添加注解

    @Entity
@Table(name = "word")

    使用的注解都是javax.persistence.*包下的;

    # b.按需设置主键生成策略

    这里使用的是数据库自增

      @Id
  @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long id;

    # c.按需设置字段的默认值

      @Column(columnDefinition = "DATETIME DEFAULT CURRENT_TIMESTAMP")
  private LocalDateTime createTime;

    # 4.修改启动类

    在启动类上添加实体扫描

    @EntityScan("com.example.xxx.xxx.entity")

    basePackages指定为mybatis-plus自动生成的实体类所在包

    # 最后

    如果丢失了建表语句，可以借助jpa使用代码生成数据库表，可以避免再去手动一个个建表。好像还有mybatis-enhance-actable这样的工具，但是使用下来，感觉还是jpa的自动建表比较好用。
